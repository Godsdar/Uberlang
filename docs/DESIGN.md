## 1. Видение

Uberlang — это **этимологический проводник**, а не «ещё один переводчик».
Продукт показывает, как слово путешествует по языкам и где встречается
с родственными словами другого языка.

Позиционирование: «введи слово — увидь его происхождение и родство».
Основная ценность — не перевод (это коммодити), а **связь и объяснение**.

Не-цели (осознанно):
- не соревноваться с DeepL/Google Translate по качеству перевода;
- не поддерживать все языки мира (фокус: en, ru, es, fr и их семьи);
- не собирать персональные данные и телеметрию.

---

## 2. Принципы

1. **Мгновенно.** Перевод появляется во время набора, без кнопки.
2. **Объяснимо.** Каждый вывод подкреплён данными (язык, форма, кто источник).
3. **Честно о пробелах.** Если общего корня нет — так и говорим.
4. **Лицензионно чисто.** Данные — Wiktionary (CC BY-SA), атрибуция в UI.
5. **Один словарь — много поверхностей.** Общее ядро для десктопа, веба и расширения.
6. **Приватность.** Ноль аналитики по умолчанию; всё локально, кроме запросов к словарю.

## 4. UX-сценарии

Легенда: ✅ реализовано · 🟡 частично · ⬜ запланировано · 💡 идея.

### 4.1 Реализовано / частично

#### S1 — Живой перевод при наборе ✅
- **Триггер:** пользователь печатает в поле слева.
- **Поток:** ввод → debounce 400мс → результат справа. Кнопки нет.
- **Успех:** перевод появляется < ~1.5с, без действий пользователя.
- **Края:** пустой ввод → плейсхолдер; ошибка сети → статус в футере, не блокирует.
- **Заметка:** предложение переводит MyMemory, слова — Wiktionary; возможны расхождения.

#### S2 — Пословный разбор ✅
- **Триггер:** ввод текста → панель «Word-by-word analysis».
- **Поток:** токены-чипы; клик по чипу → POS, глосса, альтернативы.
- **Успех:** для каждого слова видна часть речи и перевод.
- **Края:** первые 8 уникальных слов; неизвестное слово → пустая цепочка.

#### S3 — Этимологическое древо слова ✅
- **Триггер:** выбран чип-S2.
- **Поток:** граф «общий предок» сверху + две ветви (источник / перевод).
- **Успех:** видно, где слова сходятся (напр. `water ↔ вода` → PIE `*wódr̥`).
- **Края:** нет общего корня → честная подпись «No shared etymon».

#### S4 — Статическое индоевропейское древо ✅
- **Триггер:** вкладка «Language tree».
- **Поток:** SVG-древо всей семьи, четыре языка подсвечены.
- **Успех:** понятна структура семьи; горизонтальный скролл для широкого древа.

#### S5 — Выбор языка из древа ✅
- **Триггер:** клик по подсвеченному узлу.
- **Поток:** язык становится целевым, происходит возврат в переводчик.

#### S6 — Смена языков ✅ · **S7 — Копирование** ✅ · **S8 — Темы light/dark** ✅
- Swap ⇄ меняет языки и текст; Copy кладёт перевод в буфер; тема по умолчанию из ОС, переключается в AppBar.

#### S9 — Поиск слова на любой веб-странице (расширение) ✅
- **Триггер:** выделил слово → ПКМ → «Etymology of …», либо иконка расширения.
- **Поток:** popup с вводом, выбором языков и тем же древом.
- **Права:** `contextMenus`, `storage`; хосты: wiktionary, mymemory.

### 4.2 Продуктовое упрочнение (следующее)

#### S10 — Первый запуск / онбординг ⬜
- 3 шага: что это → 3 примера-«вау» (word/вода, night/noche) → подсказка «начни печатать».
- **Успех:** новый пользователь делает первое открытие за < 30 секунд.

#### S11 — Состояния: пусто / загрузка / ошибка / офлайн 🟡
- Скелетоны токенов во время анализа, ретрай при ошибке, кэш последнего результата офлайн.
- **Края:** ошибка 429 от Wiktionary → «попробуйте через минуту», не пустой экран.

#### S12 — Разбор длинного текста ⬜
- Вставить статью/абзац → показать топ-N слов по «интересности» (есть общий корень).
- **Успех:** на тексте 500+ слов пользователь находит ≥3 родственных пары.

#### S13 — История поиска ⬜
- Локальный список последних слов/пар с быстрым возвратом. Хранение — локально (IndexedDB/localStorage).

#### S14 — Избранное / коллекции ⬜
- «Мои слова», папки по темам/языкам, экспорт в CSV/Anki.

#### S15 — Поделиться древом ⬜
- Экспорт графа в PNG и пермалинк `lingua.app/w/water?to=ru`. Основа виральности.

#### S16 — Языки по умолчанию + автоопределение 🟡
- Автоопределение языка по скрипту (расширение уже умеет Cyrillic→ru). Настройка дефолтов.

#### S17 — Доступность 🟡
- Клавиатурная навигация по чипам, `aria-label`, контраст, фокус-стили, полное управление с клавиатуры.

#### S18 — Локализация UI ⬜
- RU/ES интерфейс (сейчас EN). Строки вынести в словарь.

### 4.3 Дифференциация и рост (позже)

#### S19 — Компаратор двух слов 💡
- Ввёл два слова в любых языках → «есть ли общий предок». Для P2 — киллер-фича.

#### S20 — Слово дня / лента открытий 💡
- Ежедневная пара родственников/ложных друзей. Экран-«лента» для открытия без цели.

#### S21 — Учебный цикл (SRS по этимологии) 💡
- Из разбора → карточка «почему это слово такое?» → интервальное повторение.

#### S22 — Веб-версия с SEO-страницами ⬜
- `etymology of water`, `water vs вода`, `cognates of night` — программный SEO из данных Wiktionary. Главный бесплатный канал трафика.

#### S23 — Глобальный хоткей / трей 💡
- Выделил слово где угодно → хоткей → оверлей с древом.

#### S24 — Режим учителя 💡
- Готовые наборы примеров, экспорт слайдов, режим проектора.

#### S25 — Публичный API / MCP 💡

## 5. Информационная архитектура

```
Десктоп
├─ Translator            (по умолчанию)
│   ├─ языковая панель (From ⇄ To)
│   ├─ ввод / перевод
│   └─ панель разбора (чипы → древо слова)
└─ Language tree         (статическое древо семьи)

Расширение (Chrome/Edge/Firefox)
└─ Popup поиска слова + context menu на странице

Веб (планируется)
├─ приложение (тот же renderer, ядро в браузере)
└─ SEO-страницы слов/пар (генерируются из Wiktionary)
```

## 6. Данные, ограничения, зависимости

- **Языки:** en, ru, es, fr (плюс исторические/прото- языки в древе).
- **Этимология:** English Wiktionary (wikitext + rendered ety-tree, CC BY-SA).
- **Переводы:** Wiktionary translations → MyMemory → (DeepL/LibreTranslate при ключе).
- **Лимиты:** анализ первых 8 уникальных слов; троттлинг запросов к Wiktionary.
- **Приватность:** без аккаунтов и телеметрии; кэш — в памяти/локально.
- **Известные пробелы:** не все слова имеют полную цепочку; часть пар не сходится (это нормально и показывается честно).

## 7. Метрики

**North Star:** число «открытий» в неделю — сессий, где пользователь нашёл общий корень.

Поддерживающие: D1 retention, доля сессий с разбором (не только перевод), число
расшаренных картинок/ссылок, установки расширения, возвраты после первого запуска.
