# Uberlang — спецификация графики и моушена

Статус: черновик · Версия 0.1 · Обновлено: 2026-10-01
Решения: [ADR-007 (стек)](decisions/ADR-007-graphics-stack.md) ·
[ADR-008 (визуальный язык)](decisions/ADR-008-visual-language.md)

> «Вау»-графика — часть ценности, а не декор. Но вау подчиняется смыслу:
> каждый эффект объясняет родство, а не просто украшает.

---

## 1. Стек

`d3-hierarchy` (раскладка) + **React-SVG** (рендер) + `d3-zoom` (pan/zoom, императивно)
+ `motion` (анимация, авто-reduced-motion) + `modern-screenshot` (PNG).
Реконструкции — `*` + `<sub>` для ларингалов. Будущая сеть — ленивый `@xyflow/react`
или `Sigma.js + graphology` (никогда в popup).

---

## 2. Визуальный язык (Atlas)

- Палитра: `ink`, `ultramarine` (общий предок), `gold` (единственный «вау»-акцент),
  `verdigris` (заимствование), нейтральный прото; фоны — пергамент/бумага (light) и ночное небо (dark).
- **Иерархия формой, а не числом цветов.**
- Узлы по возрасту/уровню (форма), линии по `relation` (сплошная/пунктир/точечная).
- Серифный курсив для `*форм`; ларингалы — `<sub>`, не фичи шрифта.
- Тема = `mode × skin` (atlas | constellation | plate) ремапом токенов.

## 4. Моушен-токены

```
dur:   120 · 200 · 280 · 420 · 640 · 900 ms
ease:  enter (.16,1,.30,1) · exit (.40,0,1,1) · move (.20,0,0,1)
       emphasis (.34,1.56,.64,1) · draw (.33,0,.15,1)
stagger: node 80ms · branch 120ms · cap 1200ms
```
Смысловые правила:
1. **Рост = из истока в настоящее**: ПИЕ — корни внизу (под землёй), современные
   слова — крона сверху; «aha» вспыхивает в корне.
2. **Глубина = расстояние, длительность, непрозрачность** — старость формы чувствуется.
3. Схождение — две линии, один момент, **одна** рябь.
4. **Определённость = стиль линии** (сплошная/пунктир/точечная) из `relation`.
5. Пульсирует только «ты здесь», ровно два такта, потом тихо.
6. **Отсутствие анимируется честно** — тянутся и останавливаются.
7. В простое ничего не движется (кроме ≤6% дрейфа в созвездии ≥6s, off при reduced-motion).
8. Анимируем только `transform`/`opacity`/`stroke-dashoffset`; без тяжёлого blur/box-shadow.
9. **Один герой за раз** — есть планировщик активной последовательности.

MUI-обвязка: `theme.transitions.duration` = 120/200/280, easing — наши кривые;
`prefers-reduced-motion` глобально в `CssBaseline` + ручной тумблер.

## 5. Гардрейлы (где «вау» вредит)

- Один герой за раз; M1 — единственная длинная сцена, играется **один раз за всё время**.
- Созвездие: ≤150 узлов на старте, ≤8 видимых подписей, кластеризация до отрисовки.
- Пол кегля 12–13px; ниже 0.8 зума подписи скрываются; canvas **никогда** не единственный носитель смысла.
- Никакого scroll-параллакса, вечных циклов, вращения, мерцания >3Hz.
- Раскладка созвездия — в `requestIdleCallback`, ≤50ms, сначала skeleton; не блокирует переводчик.
- Не анимировать, пока поле ввода в фокусе и пользователь печатает.
- `relation` честно кодирует наследование/заимствование; «нет общего корня» показывается.
- A11y: у каждого цвета есть форма/вес/текст-двойник; фокус виден; `aria-live` скупой и debounced.
- Popup MV3 (360×~500): только короткий inline-reveal ≤600ms, **без созвездия и кинематографичного M1**.

## 6. Приоритет сборки

1. **M2+M3** — движок сходжения (SVG-граф + рисование) и **M1** поверх него. Ядро идентичности.
2. **M6** — «плита» шаринга (дёшево, высокий возврат, рост).
3. **M5** — апгрейд `LanguageTree` в «атлас».
4. **M7** — микроинтеракции (непрерывно).
5. **M4** — «созвездие» (нужна модель `CognateEdge` в `core/`; самый большой объём).

---

## 7. План миграции (инкрементально, без выбрасывания кода)

1. Ввести шов: чистый тип `{ nodes, links }` + `layoutTree()` на `d3-hierarchy`; кормить им и старый `EtymologyGraph`.
2. Новый презентационный `<EtymologyTreeSvg>` без анимации рядом со старым (feature-flag).
3. Паритет pan/zoom на `d3-zoom`; проверка в браузере, Electron и popup.
4. Слой `motion`: draw-on + spring, под `useReducedMotion`.
5. Экспорт через `modern-screenshot` (шрифты self-host).
6. Переключить дефолт, старый — за флаг на один релиз, затем удалить.
